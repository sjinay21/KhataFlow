# KhataFlow

KhataFlow is a responsive personal-finance web application inspired by the simplicity of a digital Khata book.

## Product Purpose
KhataFlow helps users understand their monthly income, essential expenses, lifestyle spending, savings, and future goals. It serves as a personal financial companion to track, plan, and visualize finances simply.

## Planned Technology Stack
- **Frontend**: Next.js, React, JavaScript, JSX, Tailwind CSS
- **Backend**: Node.js, Express.js, JavaScript
- **Database**: MongoDB
- **Authentication**: JWT, bcrypt
- **Important**: TypeScript is not used in this project.
